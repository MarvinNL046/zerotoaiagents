# SEO Content Roadmap Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Expand the site's highest-leverage SEO surface area by improving discoverability of existing comparison pages and adding three new pillar/hub pages that broaden topical authority beyond pure review intent.

**Architecture:** Reuse the existing dynamic comparison route for new comparison slugs instead of building new page templates. Add new content as first-class guide/blog routes inside the current App Router structure, then connect them through the existing compare hub, reviews hub, guides hub, header navigation, sitemap, and related-link components.

**Tech Stack:** Next.js App Router, next-intl, dynamic comparison route (`src/app/[locale]/compare/[comparison]/page.tsx`), guide pages under `src/app/[locale]/guides`, Convex-backed blog under `src/app/[locale]/blog`, metadata API, JSON-LD/FAQ SEO components.

---

## Current State

The codebase already has more SEO surface area than the nav and sitemap expose:

- Existing comparison routes already resolve dynamically for:
  - `cursor-vs-windsurf-vs-github-copilot`
  - `claude-code-vs-cursor`
  - `github-copilot-vs-windsurf`
  - `cursor-vs-devin`
  - `crewai-vs-autogen-vs-langgraph`
- The compare dropdown and sitemap still expose only five featured comparisons.
- `/reviews` already functions as the "Best AI Coding Agents 2026" hub.
- `/guides/ai-coding-agent-statistics` already exists and is now the primary data/linkbait asset.
- `/blog` exists and is backed by Convex blog posts, but there is no dedicated "AI Agents News" hub page.
- There is currently no broad non-coding "What Are AI Agents?" pillar.
- There is currently no "Principles of Building AI Agents" guide.

## Scope

This roadmap covers four workstreams:

1. Comparison discoverability expansion
2. Broad-topic pillar content expansion
3. News hub creation
4. Framework/builder guide creation

## Non-Goals

- Industry-specific real estate/insurance content in this phase
- Outreach/distribution execution (Reddit, HN, Discord, Product Hunt)
- Major data model changes to the compare engine
- Rewriting the existing blog CMS flow

## Rollout Order

Use this order to maximize SEO return while minimizing implementation risk:

1. Workstream 1: comparison discoverability
2. Workstream 2: broad "What Are AI Agents?" pillar
3. Workstream 4: "Principles of Building AI Agents"
4. Workstream 3: "AI Agents News" hub

## Why This Order

- Workstream 1 is the fastest lift because most comparison pages already resolve.
- Workstream 2 broadens topical authority and captures the largest information-intent gap.
- Workstream 4 monetizes the existing framework review inventory.
- Workstream 3 matters, but it is strongest once you have more blog/news entries to funnel into it.

## Success Metrics

Track these after launch:

- New indexed compare URLs in Search Console
- Impressions/clicks for:
  - `claude code vs cursor`
  - `copilot vs windsurf`
  - `cursor vs devin`
  - `what are ai agents`
  - `principles of building ai agents`
  - `ai agents news`
- Internal link destinations receiving impressions uplift:
  - `/reviews`
  - `/compare`
  - framework reviews
  - statistics guide

## Risks

- Broadening from "coding agents" to "AI agents" can dilute topical focus if the new pages are thin or disconnected.
- Dynamic compare pages that are technically live but poorly linked may still remain effectively invisible.
- The news hub will underperform if it is created once and then left stale.

## Recommendation

Treat this as a 2-sprint plan:

- Sprint 1: Workstream 1 + Workstream 2
- Sprint 2: Workstream 4 + Workstream 3

That gives you one quick-win sprint and one authority-expansion sprint.
